# 像素纪元 · Pixel Eras

用 Canvas 程序化场景演示游戏画面从 8-bit 到风格化渲染的演进。

## 核心互动

图形年代旋钮，同一场景穿越五种图形技术。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，使用相对路径 `base: './'`，可部署到 GitHub Pages 的任意子路径。

## 技术栈

Vue 3 · TypeScript · Vite · CSS / SVG / Canvas（本作全部视觉为原创代码绘制，无外部图片与付费 API 依赖）。
